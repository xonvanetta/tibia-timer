# Tibia Timer

**Tibia Timer** is a collection of user-friendly timers for the MMORPG Tibia. These timers are designed to assist players with various game mechanics, such as Mastermind (10-minute cycles), Spawn Ebb and Flow, and the Rotten Blood Boss quest. With pre-configured settings and cross-platform support, Tibia Timer helps you stay on top of the action.

---

## Features

### 1. Mastermind Timer
- **Interval**: 10 minutes.
- **Alerts**: Sounds an alarm 1 second before the countdown resets.
- **Description**: Designed to track Mastermind mechanics seamlessly with continuous automatic resets.

### 2. Rotten Blood Boss Timer
- **Interval**: 90 seconds.
- **Alerts**: Sounds an alarm 5 seconds before the countdown resets.
- **Description**: Tailored specifically for the "Rotten Blood" boss encounter, ensuring optimal timing for each phase.

### 3. Ebb and Flow Timer
- **Interval**: 120 seconds.
- **Alerts**: Sounds an alarm 15 seconds before the countdown resets.
- **Description**: Tracks spawn ebb and flow mechanics for efficient hunting and resource planning.

---

## How It Works
Each timer runs as a standalone application and provides:
- **Small Window Display**: Shows the countdown timer and allows basic controls.
- **Audible Alerts**: Notifies you just before the timer resets.
- **Automatic Resets**: Continuously tracks your activities without manual intervention.
